# Stock Market Trend Prediction System

A Python and Streamlit educational project demonstrating stock-data analysis using:

- Principal Component Analysis (PCA) and eigenvectors
- Gradient descent optimization using derivatives
- A simple differential-equation-based price projection
- Historical test metrics: MAE, RMSE, MSE and directional accuracy

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

1. Push `app.py`, `requirements.txt`, and `README.md` to a public GitHub repository.
2. Sign in at https://share.streamlit.io/
3. Choose **Create app**, select this repository, branch `main`, and file `app.py`.
4. Deploy.

## Notes

This is an educational prototype, not financial advice. The next-session estimate is uncertain.
The differential-equation projection assumes a constant average growth rate and is illustrative only.
